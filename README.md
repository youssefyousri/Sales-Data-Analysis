# Sales Data Analysis & Power BI Dashboard

## Project Overview

This project analyzes sales data to identify key business insights and sales performance trends.

The project includes data cleaning and analysis using Python, followed by visualization and dashboard development using Power BI.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Excel
- Power BI

## Project Files

- `Sales_Data_Raw.csv` — Original sales dataset
- `Sales_Data_Cleaned.csv` — Cleaned sales dataset
- `Sales_Analysis.ipynb` — Python data cleaning and analysis
- `Sales_Dashboard.pbix` — Power BI dashboard
- `Sales_Business_Insights.pdf` — Business insights report

## Key Business Insights

### Sales by Product Category

- Clothing generated approximately 16.4M in sales.
- Furniture generated approximately 15.4M.
- Electronics generated approximately 15.2M.
- Food generated approximately 12.8M.

### Sales by Region

- North recorded approximately 15.6M in sales.
- East recorded approximately 15.2M.
- West recorded approximately 15.0M.
- South recorded approximately 13.9M.

### Sales by Representative

- David recorded approximately 13.7M in sales.
- Eve recorded approximately 12.9M.
- Bob recorded approximately 11.8M.
- Alice recorded approximately 11.5M.
- Charlie recorded approximately 9.9M.

### Monthly Sales

Monthly sales varied throughout the year, with January recording approximately 6.4M and September approximately 3.8M.

### Profit by Sales Channel

Profit was distributed relatively evenly between Online and Retail sales channels.

- Retail: approximately 3M — 50.54%
- Online: approximately 3M — 49.46%
